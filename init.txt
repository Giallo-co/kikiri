GUIA DE INICIO RAPIDO - KIKIRI

Siga estos comandos en estricto orden desde la raíz del proyecto para inicializar el entorno.

1. Instalar dependencias y vincular los subproyectos:
   npm install

2. Configurar variables de entorno:
   Copie el archivo .env.example a .env en la raíz del proyecto.
   Asegúrese de configurar DATABASE_URL con las credenciales correctas.
   Asegúrese de configurar JWT_SECRET_KEY con una clave secreta super segura.

3. Sincronizar la base de datos y generar Prisma Client:
   npx prisma migrate dev

4. Ejecutar el entorno.
   Opción A - Levantar el backend y el frontend simultáneamente:
   npm run dev:all

   Opción B - Levantar únicamente el servidor del backend:
   npm run dev:backend

   Opción C - Ejecutar las pruebas automatizadas del backend:
   npm run test:backend
